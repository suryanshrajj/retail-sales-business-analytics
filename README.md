# Retail Sales Business Analytics

A retail sales analysis project using Microsoft Excel and Power BI to explore business performance, analyse sales data, and communicate insights through visualisations.

## Tools & Technologies
- **Microsoft Excel** — Data analysis, PivotTables and sales summaries.
- **Microsoft Power BI** — Interactive dashboards and data visualisation.

## Project Components

### Excel — Retail Sales Analysis
**Status:** Completed

Analysed retail sales data using Excel and PivotTables to explore sales performance and identify relevant business trends.

### Power BI — Retail Sales Dashboard
**Status:** In Progress

Developing an interactive dashboard to present sales KPIs, compare performance, and communicate business insights.
